# College Feedback Management System

A web-based College Feedback Management System built using Node.js, Express.js, HTML, CSS, JavaScript, and Supabase.

## Features

- Submit student feedback
- Store feedback in Supabase
- View all feedback
- Edit existing feedback
- Delete feedback
- Search feedback by student name
- Filter feedback by department
- Filter feedback by rating
- Clear filters
- Feedback dashboard
- Display total feedback
- Display average rating
- Display highest rating
- Display lowest rating
- Simple navigation between pages
- Form validation

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- Supabase
- REST API
